# A Love Story, One Year In

A cinematic 1st anniversary website built with Next.js 14 + Framer Motion.

## Personalise

Edit `data/story.ts` to change all names, dates, captions, the letter, and every line of copy.

## Media

Upload your files to:
- `public/images/` → photo-01.webp through photo-06.webp
- `public/videos/` → memory-01.mp4 through memory-04.mp4
- `public/audio/`  → love-story.mp3

## Deploy

Connect this GitHub repo to [Vercel](https://vercel.com).  
Framework: Next.js. No environment variables required.
